# きょうのよてい — 0円PWA MVP

## できること
- 今日の予定を一覧表示
- 現在の予定を強調
- 完了した予定をチェック表示
- 「おわった！」で次へ進む
- 誤操作時に「ひとつもどす」
- いつもの予定を保存
- 昨日の予定を今日へコピー
- よく使う予定を追加
- 予定の追加・編集・削除
- ドラッグ&ドロップで並べ替え
- 子どもの名前設定
- データは端末内のlocalStorageに保存
- 外部サーバー・ログイン・AI・広告なし

## 重要な制約
このMVPは端末ごとに独立しています。
パパのiPhoneとママのiPhoneの予定は自動同期しません。

## iPhoneで使う方法
PWAとして使うには、HTTPSで公開したURLをSafariで開き、
「共有」→「ホーム画面に追加」を選びます。

無料ホスティングを使う場合は、GitHub Pagesなどにこのフォルダを配置できます。
